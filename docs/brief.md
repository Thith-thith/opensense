# OpenSense
### Design with intention.
**Beautiful UI. Exceptional UX. Designed for humans.**

An open-source design intelligence skill for AI coding agents.

## 1. The Idea

OpenSense is a universal AI skill that helps AI coding agents create clean, beautiful, intuitive, and high-quality digital experiences that feel thoughtfully crafted by a skilled human designer.

The goal is not simply to make AI-generated interfaces look prettier. OpenSense aims to change how AI agents approach UI/UX design — moving from generating functional interfaces to crafting meaningful digital experiences.

OpenSense should be usable across different AI coding agents, frameworks, and platforms.

## 2. The Problem

AI has made building applications easier than ever. However, many AI-generated interfaces share the same problems:

- Generic layouts and repetitive design patterns.
- Excessive cards, badges, labels, and explanatory text.
- Poor typography and visual hierarchy.
- Interfaces that lack a distinct design identity.
- UX decisions based on implementation convenience rather than human behavior.
- Responsive designs that simply shrink desktop layouts.
- Products that feel AI-generated instead of intentionally designed.

People may appreciate AI, but they won't necessarily invest in products that feel generic or easily replaceable by their own AI agent.

The challenge is no longer just building software. It is creating products that people trust, enjoy, and find valuable.

## 3. The Vision

Help AI agents think and work like experienced UI/UX designers.

OpenSense should understand that great design is not about adding more elements. It is about making the right design decisions.

Every pixel, word, color, interaction, and component should have a reason to exist.

The result should feel:
- Beautiful, without unnecessary decoration.
- Minimal, without sacrificing functionality.
- Intuitive, without excessive explanation.
- Distinctive, without blindly following trends.
- Professional, without feeling sterile or generic.
- Human-centered, without relying on assumptions about users.

## 4. Core Design Philosophy

### Human Value Over AI Output
The objective is to create products people genuinely want to use, not merely interfaces AI can generate.

### Beauty With Purpose
Every visual element must contribute to the product's identity, usability, or communication.

### Less Words, More Meaning
Prefer visual hierarchy, concise microcopy, recognizable icons, and meaningful patterns over unnecessary paragraphs, labels, badges, and descriptions.

### Context Over Trends
Design must fit the product, audience, culture, language, environment, and user behavior. Do not force one visual style onto every product.

### Clarity Over Complexity
Users should understand where they are, what they can do, and what happens next with minimal cognitive effort.

### Craftsmanship Over Completion
Working code is not the finish line. Visual refinement, interaction quality, accessibility, and usability matter.

### Consistency Without Monotony
Maintain coherent design systems while creating distinctive and intentional compositions.

## 5. Core Capabilities

OpenSense should guide AI agents through:

1. **Design Context Intelligence** — Understand the existing product, brand, codebase, design system, and constraints.
2. **Human-Centered UX** — Consider user goals, behaviors, culture, digital literacy, and real-world context.
3. **UX Architecture** — Create intuitive information architecture, navigation, workflows, and interaction patterns.
4. **Visual Excellence** — Master typography, color, spacing, composition, hierarchy, imagery, and component design.
5. **Information Economy** — Remove redundant text, excessive badges, unnecessary labels, and visual noise.
6. **Cross-Platform Experience** — Design intentionally for mobile, tablet, desktop, and other relevant platforms.
7. **Design QA & Refinement** — Inspect the implementation, identify weaknesses, and refine until the experience feels cohesive and polished.

## 6. How OpenSense Should Work

OpenSense should adapt its workflow to the task rather than applying a heavy process to every request.

- **Discover:** Understand the existing product and design context.
- **Design:** Establish the appropriate UX and visual direction.
- **Implement:** Translate design decisions into high-quality frontend code.
- **Improve:** Refine existing interfaces without unnecessarily rebuilding them.
- **Review:** Evaluate visual quality, usability, accessibility, and responsiveness.

The skill should use available tools such as browser previews, screenshots, project files, and design references when supported by the host agent. It must not pretend to have inspected or validated an interface when it has not.

## 7. What OpenSense Must Avoid

- Generic AI-generated SaaS aesthetics.
- Overusing cards, gradients, badges, shadows, and rounded containers.
- Unnecessary explanatory text.
- Forcing minimalism on every product.
- Blindly copying Apple, Linear, or other design references.
- Inventing product features, brand claims, or user research.
- Removing important information in the name of simplicity.
- Treating accessibility as optional.
- Declaring an interface finished just because the code compiles.

## 8. Initial Project Scope

Build OpenSense as a portable, open-source Agent Skill using the Agent Skills standard.

The initial version should focus on:
- A concise, powerful `SKILL.md`.
- A clear design philosophy.
- Practical UI/UX design guidelines.
- Typography and information economy principles.
- Visual design and interaction guidelines.
- Responsive design and accessibility.
- A repeatable design review process.

Keep the skill modular and use progressive disclosure. Do not overload the main `SKILL.md` with every design guideline.

The initial release should prioritize quality, usability, and portability over a large feature set.

## 9. Success Criteria

OpenSense is successful when AI agents using it consistently produce interfaces that:

- Feel intentionally designed rather than template-generated.
- Have strong visual identity and excellent typography.
- Communicate efficiently without unnecessary text.
- Provide intuitive and pleasant user experiences.
- Respect the product's context and users.
- Work well across relevant devices.
- Are accessible and functionally sound.
- Require less human design correction than comparable AI-generated interfaces.

Quality should be evaluated through real implementation reviews, screenshots, usability tests, and independent design feedback — not solely by the AI grading its own output.

## The Founding Belief

AI can generate an application. But generating an application does not mean creating a product people love.

The future is not about producing more interfaces, more components, or more code.

It is about creating meaningful digital experiences that people trust, enjoy, and find valuable.

**OpenSense exists to help AI agents move beyond generating interfaces and toward crafting products worth using.**
